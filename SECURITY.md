# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of Athenea:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Athenea team takes security and privacy issues seriously. If you discover a security vulnerability in Athenea, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Use GitHub's [Private Vulnerability Reporting](https://github.com/atheneaelib-elib/project-athenea/security/advisories/new) to submit your report privately.
3. If Private Vulnerability Reporting is unavailable, send an email to `security@athenea.io` with details of the issue, steps to reproduce, and impact.

### What to Include in Your Report
* Description of the vulnerability and attack vector.
* Clear steps or a minimal proof-of-concept (PoC) to reproduce the behavior.
* Affected components or endpoints.
* Potential impact on the system or user data.

### Our Commitment
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will provide a status update on triage and remediation.
* We will credit reporters in release notes (unless you request anonymity).
